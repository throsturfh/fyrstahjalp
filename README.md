# Fyrsta hjálp – leikur

Frumgerð af farsímaleik til æfinga í fyrstu hjálp fyrir björgunarsveitir (HSG). Þú ert björgunarsveitarmaður: mynd í fullum skjá, valmyndir yfir myndinni og hægt að kalla eftir lögreglu, sjúkrabíl, fleiri björgunarsveitarmönnum eða þyrlu. Fyrsta atburðarás: ofkæling á hrauni.

Spila: https://throsturfh.github.io/fyrstahjalp/

Kyrrstæð vefsíða (HTML/CSS/JS), engin uppsetning. `fyrsta-hjalp-leikur.html` er sama leikurinn í einni skrá.
